# Keichu64Kai
「契冲64改」配布ページ
# これは何？
国語問題協議会が「契冲」をベースにリニューアルしてリリースした、正字・正かなの入力をサポートすることを目的としたGoogle日本語入力用カスタムユーザー辞書「契冲64」を私が改造を加えたものです。
# 私が加えた改造って？
一、重複した仮名と漢字の踊り字を手がとどく範囲で補完しました。
一、「ら行５段動詞のルーツ＋TSUTE」で大書きの促音便「變る→變つて」を一応出力可能にしました。
# 注意事項
一部の活用はGoogle日本語IMEの単語変換の仕組みを欺く形（いわゆるHack）で出力可能にしたので、不具合を起こさないことを保証するものとしません。
# 未来の計画
動詞の連用形における音便「っ」を大書きに書き換える機能に手がとどく範囲で対応させる。
口語体における仮定形の単音節化（「~Eば」→「~Iゃ」）に手がとどく範囲で対応させる。
